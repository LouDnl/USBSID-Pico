# Cartridge Case by spotUp, LouD v1.5 remix
- Updated to be v1.5 PCB compatible
- Open top lid  
  The top lid is slightly larger to fit the notches  
  The notch holes in the top lid are also slightly wider
- Wider Pico USB opening to support clone Pico2 RGB capable boards
- Design is opensource  
  Change the case to your liking on [Tinkercad](https://www.tinkercad.com/things/7AoTmtHnQvM-usbsid-pico-v15-case)
- Also included is my PrusaSlicer project file as example
