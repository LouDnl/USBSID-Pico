=== Clock screen
image:images/configtool/screen-clock.png[link="https://github.com/LouDnl/USBSID-Pico/blob/master/doc/images/configtool/screen-clock.png",width="600"] +

*External Clock*: display only. The firmware detects an external clock source at startup and reports it in the configuration, it cannot be set from the Configtool.

*Clock link*: enables or disables the board clock link (LINK_CLOCK command 0x84, state read from configuration byte 6 bit 1). The firmware saves the configuration and reboots the board when the value changes. The Configtool disconnects and the board must be reconnected afterwards.

=== Features screen
image:images/configtool/screen-features-1.5.png[link="https://github.com/LouDnl/USBSID-Pico/blob/master/doc/images/configtool/screen-features-1.5.png",width="600"] +
image:images/configtool/screen-features-1.3.png[link="https://github.com/LouDnl/USBSID-Pico/blob/master/doc/images/configtool/screen-features-1.3.png",width="600"] +

*USB RX ringbuffer*: buffers up to 8 incoming USB packets and prevents cracks on write-heavy tunes. Default on. Listed under ADVANCED next to Preset auto detect, written with the other settings (SET_CONFIG item 17) and stored in the ini file as `rx_ring` in the `[Features]` section. The setting applies after saving the configuration and rebooting the board. Available on firmware newer than v0.8.1.

*Preset auto detect*: toggle under ADVANCED, written as SET_CONFIG item 16 (BOARD_PADETECT).

*FMOpl SID No.*: selector in the FM Opl block on the Sockets screen, enabled when FMOpl is on. The selected SID number (1 to 4) is sent with SET_CONFIG item 9 (BOARD_FMOPL) and must be a SID that has an address assigned. Selecting Unknown (0) while FMOpl is enabled clears the assignment.
