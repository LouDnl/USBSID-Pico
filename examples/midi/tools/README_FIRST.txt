Important:
These tools are examples, I provide no support for them.
You can use any midi controller to send the CC commands.

Usage information:
1. Install Python 3 (python.org installer on Windows/Mac already bundles tkinter; Linux users may need python3-tk separately)

Windows:
1. pip install -r requirements.txt
2. python patch_editor.py / python cc_controller.py

Mac:
1. pip install -r requirements.txt
2. python3 patch_editor.py / python3 cc_controller.py

Linux:
1. python -m venv usmidi
2. ./usmidi/bin/pip install -r requirements.txt
3. ./usmidi/bin/python3 patch_editor.py / ./usmidi/bin/python3 cc_controller.py
